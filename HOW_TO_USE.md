# 🚀 How to Use the Onboarding ChatBot

## Quick Start (3 Steps)

### Step 1: Open Rocket.Chat
```
http://localhost:3000
```

### Step 2: Chatbot Appears Automatically
The chatbot modal will pop up immediately!

### Step 3: Start Chatting!
Click buttons or type messages to interact.

---

## 💬 Two Ways to Use It

### Method 1: Automatic (Easiest)
1. **Open your browser**
2. **Go to**: http://localhost:3000
3. **Chatbot appears automatically** ✨
4. **Start chatting!**

### Method 2: Slash Command (From Anywhere)
1. **Go to any channel** (like #general)
2. **Type**: `/onboarding`
3. **Press Enter**
4. **Chatbot opens!** ✨

---

## 🎮 How to Interact

### Option 1: Click Buttons (Easiest)
The bot shows buttons - just click them!

```
Bot: "Hi! Ready to start?"
     [Get Started] [Skip Tour]
     
👆 Click "Get Started"
```

### Option 2: Type Messages
You can also type your responses:

```
Bot: "Hi! Ready to start?"

You type: "yes"
or
You type: "get started"
or
You type: "help"
```

Here's what a typical conversation looks like:


## 🆘 Troubleshooting

### Chatbot Not Appearing?
1. **Refresh the page** (F5 or Cmd+R)
2. **Clear cache** (Cmd+Shift+R or Ctrl+Shift+R)
3. **Type** `/onboarding` in any channel

### Buttons Not Working?
1. **Click directly on the button text**
2. **Try typing your response** instead
3. **Refresh the page** if needed

### Can't See Messages?
1. **Scroll down** in the chat area
2. **Messages appear at the bottom**

### Want to Start Over?
1. **Type** "restart" or "start over"
2. **Or refresh the page**
